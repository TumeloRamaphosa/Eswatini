# Studex Eswatini OS

The dedicated country operating system for Keenan Schofield and the Studex
Eswatini programme. This repository contains Eswatini work only.

## Mission

Turn country opportunities into governed execution through a visible team of
specialist agents. Humans set priorities and approve consequential actions;
agents research, coordinate, execute, retain institutional memory, and report
what is happening.
